# Echo Server with MCP Analytics

This is an example MCP server that demonstrates how to integrate MCP Analytics into your server for comprehensive monitoring and observability.

## Features

The echo server provides several tools to demonstrate different aspects of analytics:

### Tools
- **echo** - Simple text echo with optional delay and formatting
- **calculate** - Basic mathematical operations 
- **random** - Generate random data (numbers, strings, booleans)
- **error_demo** - Simulate different types of errors for testing

### Resources
- **echo://status** - Server status and analytics information
- **echo://config** - Server configuration details

### Prompts
- **demo_conversation** - Generate conversation templates for testing
- **error_scenarios** - Create error testing scenarios

## Analytics Integration

The server demonstrates all key analytics features:

- **Automatic event tracking** - All MCP protocol interactions are captured
- **Error monitoring** - Failed requests and exceptions are logged
- **Performance metrics** - Request timing and latency measurement
- **User context** - Intent tracking through context parameters
- **Custom identification** - User ID extraction from client info
- **Data redaction** - Sensitive information filtering

## Setup

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Build the server:**
   ```bash
   npm run build
   ```

3. **Set environment variables:**
   ```bash
   export MCP_ANALYTICS_PROJECT_ID="your-project-id"
   export MCP_ANALYTICS_API_KEY="your-api-key"
   export MCP_ANALYTICS_ENDPOINT="http://localhost:3800/api/v1/events"
   ```

4. **Start the server:**
   ```bash
   npm start
   ```

## Usage with Claude Desktop

Add to your Claude Desktop configuration:

```json
{
  "mcpServers": {
    "echo-analytics": {
      "command": "node",
      "args": ["/path/to/mcp-analytics/examples/echo-server/dist/index.js"],
      "env": {
        "MCP_ANALYTICS_PROJECT_ID": "your-project-id",
        "MCP_ANALYTICS_API_KEY": "your-api-key"
      }
    }
  }
}
```

## Testing Analytics

1. **Start the analytics server:**
   ```bash
   cd ../../
   npm start
   ```

2. **Use the server tools** in Claude Desktop or another MCP client

3. **View analytics** at http://localhost:3800

## Analytics Features Demonstrated

- **Event Tracking**: Every tool call, resource read, and prompt request is tracked
- **Performance Monitoring**: Request duration and latency metrics
- **Error Analytics**: Failed requests with full error details and stack traces
- **User Intent**: Context parameters capture what the user is trying to accomplish
- **Session Management**: Automatic session grouping and timeout detection
- **Custom Redaction**: Sensitive data filtering (passwords, tokens, etc.)

## Configuration Options

The server supports these analytics configuration options via environment variables:

- `MCP_ANALYTICS_PROJECT_ID` - Your analytics project ID
- `MCP_ANALYTICS_API_KEY` - API key for authentication  
- `MCP_ANALYTICS_ENDPOINT` - Analytics ingestion endpoint
- `NODE_ENV=development` - Enable debug logging

## Code Structure

- `src/index.ts` - Main server implementation with analytics integration
- `dist/` - Compiled JavaScript (generated by build)
- Package includes proper TypeScript configuration and dependencies

The analytics integration is minimal - just one `track()` call enables comprehensive monitoring for the entire server.
